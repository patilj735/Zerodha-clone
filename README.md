# Zerodha Clone - Full Stack Trading Platform

A full-stack stock trading platform inspired by Zerodha Kite, built using the MERN stack. The project allows users to explore stocks, manage watchlists, perform paper trading, track portfolio holdings, and visualize market data through an interactive dashboard.

---

## 🚀 Features

- 🔐 Secure user authentication using JWT & bcrypt.js
- 📈 Real-time styled stock market dashboard
- ⭐ Watchlist management system
- 💰 Paper trading functionality
- 📊 Portfolio holdings and trade history
- 📉 Interactive charts and analytics
- 📱 Fully responsive user interface
- 🌐 RESTful API integration

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/patilj735/Zerodha-clone.git
```

---

### 2️⃣ Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

---

### 3️⃣ Setup Backend

```bash
cd backend
npm install
npm start
```

---

### 4️⃣ Setup Dashboard

```bash
cd dashboard
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend folder and add the following:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```
